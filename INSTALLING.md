# Add this documentation to the repository

This ZIP is a documentation overlay, not a copy of the Rust source tree.

1. Back up or commit your current `README.md` and `BENCHMARKS.md`.
2. Extract this ZIP into the root of `Ghaith8Bit/simple-hft-engine`, allowing the two root Markdown files to be replaced.
3. Keep your existing `PORTFOLIO.md`, `LICENSE`, source code, manifests, and workflows unchanged.
4. Review the rendered Markdown on GitHub. Mermaid diagrams should render in supported GitHub Markdown views.
5. Run the repository's existing checks if you want to verify the project after adding the docs.

No Rust source files, benchmark code, CI files, or recorded performance data are changed by this bundle.
