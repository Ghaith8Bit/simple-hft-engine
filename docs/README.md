# Documentation bundle

This folder is a documentation overlay for the existing repository.

- `index.md` — reading order.
- `visual-guide.md` — all 14 diagrams rendered in order.
- `glossary.md` — short definitions.
- `diagrams/*.mmd` — editable Mermaid source for each diagram.

The root `README.md` and `BENCHMARKS.md` are replacement versions based on the repository's existing README, benchmark notes, workflow, and relevant source files.
